# ApexSoft Solutions - Story Point Estimation Policy

All user stories must be assigned story points to gauge development complexity.

## Estimation Scale (Fibonacci Sequence)
We strictly use the following values for estimating development effort:
*   **1 Point**: Trivial change. Simple text edit, environment configuration tweak, or simple print statement addition (estimated time: <2 hours).
*   **2 Points**: Minor development. Adding a simple function, writing unit tests for a single file, or generating minor endpoint validations (estimated time: half a day).
*   **3 Points**: Standard feature. Implementing a database model with migrations, writing CRUD API endpoints, or creating UI components with simple state connections (estimated time: 1-2 days).
*   **5 Points**: Complex feature. Multiple database connections, external API integrations, or multi-component UI views with complex state management (estimated time: 3-5 days).
*   **8 Points**: Epic-level task. Highly complex security system or complete framework migrations. Tasks estimated at 8 points must be broken down into smaller 2 or 3-point stories.

Do not use 4, 6, 7, or other numbers. Always justify a 5-point task with complex technical needs.
